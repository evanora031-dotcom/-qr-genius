How to Make a Wi-Fi QR Code for Guests

November 8, 2026 · QR Genius Editorial Team

Typing a long Wi-Fi password can be awkward for visitors. A Wi-Fi QR code stores the network name and connection details so compatible phones can offer to join after a scan. Here is how to create one and avoid common mistakes.

1. Set up a guest network first

When your router supports it, create a separate guest network. This can help keep visitors away from devices on your main network, depending on the router settings. Use a strong password and check that guest isolation is enabled if you need it.

2. Gather the correct network details

Find the exact Wi-Fi network name (SSID), its security setting, and the current password. Network names are case-sensitive. Use the security type supported by the generator and your router. A hidden network may need its hidden-network option enabled.

3. Generate the QR code

Open the free Wi-Fi QR code generator. Enter the SSID, select the matching security setting and enter the password when required. Generate the code and download it in a format suitable for your sign or welcome card.

Example: check the details on a guest Wi-Fi sign

Imagine a guest network named “Cafe-Guest” with WPA2-Personal security. Enter that exact network name, select the security option that matches the router, and use the real guest-network password rather than an example password. This is an illustrative setup, not a tested connection or a working QR code.

Before sharing the sign, check the network name character by character, including spaces and capital letters. Test on a device that is not already connected. If the code fails, compare the generator settings with the router before changing the QR design.

4. Test before printing

Scan the code using a compatible iPhone or Android device. Preferably test with a phone that is not already connected. Check the network name in the connection prompt and confirm that joining succeeds. Some devices require an extra tap or a dedicated QR scanner.

5. Print and place it carefully

Put the code near a reception desk, on a café table, or in a guest welcome folder. Keep adequate contrast and white space around the QR code, and test it at the actual printed size. Anyone who can scan the code may be able to use or recover the encoded credentials, so do not publish your private network password casually.

For cafés and other customer-facing spaces, a Wi-Fi sign can help guests connect while a separate QR code can make it easy to ask questions. What if a Wi-Fi QR code will not connect on iPhone or Android?

First, check that the phone is scanning a Wi-Fi QR code rather than an ordinary website link. On supported iPhones and Android phones, the camera or built-in QR scanner may offer a prompt to join the network. If no prompt appears, try the device’s QR scanning feature or enter the Wi-Fi details manually. Support varies by device and operating-system version.

If the phone recognizes the code but cannot join, compare the encoded network name, password, and security type with the router settings. Watch for capital letters, spaces, and special characters in the SSID or password. Check whether the guest network is enabled and whether a hidden network requires an additional setting. A code cannot fix a weak signal, a router outage, or a network that blocks new connections.

Test with an iPhone and an Android device when available, preferably devices that have not joined the network before. Confirm that the connection works, not just that the camera recognizes the QR pattern. If the password or security settings change, regenerate the static code and replace the sign. Never put private network credentials on a public sign.

What if the Wi-Fi password changes?

A static Wi-Fi QR code contains the old password. If you change the password, network name or relevant security setting, generate and print a replacement code.

Do guests need a special app?

Many modern phones can recognize Wi-Fi QR codes with their camera or built-in scanner. Compatibility varies by device and operating system. Always offer a manual way to enter the network name and password for guests whose phones cannot use the QR code.
